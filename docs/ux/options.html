How the skills in the post work

Recipe cards for your AI

A skill is a set of written instructions Claude reads before it starts a job, like handing a new designer your studio's style guide. You install it once, then call it by name.

1. InstallOne command adds the skill to Claude Code. Example: Impeccable's command is /plugin marketplace add pbakaus/impeccable.
2. Call itType its command, for example /impeccable critique on a screen. Claude follows that skill's rules instead of its own defaults.
3. What changesFewer "AI made this" tells: beige palettes, cards inside cards, vague buttons like "Continue", pointless pulsing dots.

Part 2 · How we build the mockup

Three ways to get from this page to your buyer flow

All three end in a link you can drop in team chat. The tokens stay a proposal for Lane B, who owns the real styles in the app.

My pick

1. Clickable prototype

I build the 8 buyer screens as one page you tap through like the real app, including the detours (offer expired, not enough balance, closed popup). A tokens sheet sits at the top.

  • You feel the tap count yourself, which is the friction pass
  • Doubles as the storyboard for the demo video
  • Then Impeccable critiques it before you share
about 1.5 hsetup: 1 plugin

2. Design canvas

Claude's Design canvas (it's on your account) plus a Design System page. Every screen and state laid out side by side as artboards, like a Figma board.

  • Best for seeing the whole state matrix at once
  • Not clickable, so the tap count stays on paper
  • Design System page is easy for Lane B to read
about 1.5 hsetup: none

3. Open Design app

Meng To's pick: a free desktop studio that drives Claude Code from a DESIGN.md file and shows live previews.

  • Nice studio feel, good for later projects
  • New app to install and learn on a deadline day
  • Output lives in that app, not in the repo
about 2.5 hsetup: desktop app
